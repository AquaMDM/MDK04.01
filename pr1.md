# Михайлов Д.М. ИСП251
## МДК04.01 Практическая работа 1. Разработка плана внедрения
## Тема: Система учёта книг в библиотеке

### Цели и задачи:
#### Цель 1 - Ускорить обработку заявок пользователей
#### Цель 2 - Обеспечить единый учёт обращений
#### Цель 3 - Снизить вероятность потери заявок
#### Цель 4 - Сформировать отчётность по обращениям
#### Задача 1 - Провести анализ работы
#### Задача 2 - Подготовить среду для работы
#### Задача 3 - Настроить систему
#### Задача 4 - Протестировать систему
#### Задача 5 - Обучить пользователей
#### Задача 6 - Запуск системы

### Анализ работы
#### Содержание работ: Сбор требований к проекту, формирование всех задач к выполнению по мере разработки проекта, анализ текущей работы для отчётов 
#### Результат: Чёткий план работы и требования проекта
#### Ответственный: Руководитель проекта
#### Необходимые ресурсы: Интернет

### Подготовить среду для работы
#### Содержание работ: Выбор программы для работы, сбор данных для будущей базы данных и инфраструктуры
#### Результат: Подготовленная среда для внедрения
#### Ответственный: Системный администратор
#### Необходимые ресурсы: Программное обеспечение

### Настроить систему
#### Содержание работ: Настройка основной функциональной составляющей проекта, базы данных и второстепенных функций (фильтр книг, права доступа и т.д.)
#### Результат: Тестовая версия проекта
#### Ответственный: Системный администратор
#### Необходимые ресурсы: Программное обеспечение

### Протестировать систему
#### Содержание работ: Проверка всех функций проекта на работоспособность и ошибки, возможных сценариев пользователей и поиск уязвимостей в защите данных
#### Результат: Отчёт о сбоях и исправлениях
#### Ответственный: Специалист поддержки и системный администратор
#### Необходимые ресурсы: Устройства с разными платформами

### Обучить пользователей
#### Содержание работ: Обучение пользователей в пользовании системы, написание пояснений и инструкций к работе системы, возможные корректировки в проекте на случай проблем с ориентацией пользователей по системе
#### Результат: Обученные пользователи и готовый проект
#### Ответственный: Специалист поддержки
#### Необходимые ресурсы: Рабочая версия проекта для обучения

### Запуск системы
#### Содержание работ: Запуск проекта в открытый доступ и дальнейшая поддержка путём выпуска обновлений
#### Результат: Проект функционирует и активно используется
#### Ответственный: Системный администратор и руководитель проекта
#### Необходимые ресурсы: Готовый проект

### Риски:
#### Потеря данных проекта
#### Возникновение критических ошибок влияющие на работоспособность системы
#### Отклонения в сроках
#### Недостаток/отсутствие требуемых ресурсов во время разработки
#### Выгорание сотрудников
#### Нестабильная работа при внедрении проекта
#### Расхождения итогового продукта и поставленных требований и задач изначально
